# Интеграция реального iperf3 binary

## Обзор интеграции

Приложение теперь использует **настоящий статически линкованный iperf3 binary** версии 3.19.1 для ARM64 архитектуры вместо mock данных.

## Архитектура решения

### Ключевые компоненты

1. **iperf3 binary** - статически скомпилированный для arm64-v8a (16MB)
2. **IperfJsonModels.kt** - модели для парсинга JSON вывода iperf3  
3. **IperfEngineImpl.kt** - обновленная реализация с реальным процессом выполнения
4. **Fallback система** - автоматический переход на mock данные при ошибках

### Workflow выполнения тестов

```
1. Получение пути к binary из jniLibs (Android обрабатывает права автоматически)
2. Построение команды iperf3 с JSON выводом (-J флаг) 
3. Установка переменных окружения (TMPDIR, TEMP, TMP -> cacheDir)
4. Запуск процесса с ProcessBuilder
5. Парсинг построчного JSON вывода в реальном времени
6. Конвертация в LiveMetricsTick для UI
7. Обработка финальных результатов из JSON
8. Fallback на mock при ошибках
```

## Технические детали

### Размещение binary

- **Источник**: `app/src/main/jniLibs/arm64-v8a/libiperf3.so` (16MB)
- **Runtime**: автоматически размещается в `/data/app/package/lib/arm64-v8a/libiperf3.so` 
- **Права**: Android автоматически устанавливает правильные executable права

### Парсинг JSON

Iperf3 выводит JSON в следующих форматах:

- **start**: информация о начале теста
- **intervals**: данные по секундам (throughput, retransmits, jitter, packet loss) 
- **end**: финальная статистика
- **error**: ошибки выполнения

### Поддерживаемые протоколы

- **TCP**: пропускная способность, RTT, retransmits
- **UDP**: пропускная способность, jitter, packet loss, ограничение bitrate

### Fallback логика

Если процесс iperf3 падает или выдает некорректные данные, система автоматически переходит на mock engine с пометкой в логах.

## Команды для тестирования

### Запуск локального iperf3 сервера

```bash
# TCP сервер на порту 5201
iperf3 -s

# UDP сервер на порту 5202
iperf3 -s -p 5202

# С JSON выводом для отладки
iperf3 -s -J
```

### Тестирование с реальным сервером

1. Установите iperf3 на сервер: `apt install iperf3`
2. Запустите сервер: `iperf3 -s`
3. В приложении укажите IP сервера и протестируйте

## Диагностика проблем

### Логи интеграции

Все логи iperf3 процесса сохраняются с тегом `IperfEngine`:

```bash
adb logcat -s "IperfEngine:*"
```

### Решение Permission denied (error=13)

**Проблема**: Android 10+ блокирует выполнение binary из app private storage.

**Решение**: Используем `jniLibs/arm64-v8a/libiperf3.so` подход:
1. Binary размещается как native library 
2. Android автоматически устанавливает executable права
3. Устанавливаем переменные окружения TMPDIR/TEMP/TMP
4. iperf3 использует доступную cacheDir для временных файлов

### Типичные проблемы

1. **Permission denied** - решено через jniLibs подход ✅
2. **Таймаут соединения** - проверьте доступность сервера
3. **JSON парсинг падает** - система переходит на fallback
4. **Нет сети** - iperf3 вернет ошибку подключения
5. **Temporary file errors** - решено через TMPDIR=cacheDir ✅
