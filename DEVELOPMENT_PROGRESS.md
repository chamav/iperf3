## Архитектура
### Файловая структура (39 Kotlin файлов)
```
app/src/main/kotlin/com/iperf3client/
├── IperfApplication.kt              # Application класс
├── MainActivity.kt                  # Главная активность
├── data/                           # Data слой
│   ├── database/                   # Room база данных
│   │   ├── IperfDatabase.kt
│   │   ├── Converters.kt
│   │   ├── dao/                    # DAO интерфейсы
│   │   └── entity/                 # Сущности БД
│   ├── engine/                     # Engine реализации
│   │   └── IperfEngineImpl.kt      # Mock iperf3 engine
│   └── repository/                 # Реализации репозиториев
├── domain/                         # Domain слой
│   ├── model/                      # Доменные модели
│   ├── repository/                 # Интерфейсы репозиториев
│   └── usecase/                    # Бизнес-логика
├── presentation/                   # UI слой
│   ├── component/                  # Переиспользуемые компоненты
│   ├── navigation/                 # Навигация
│   ├── screen/                     # Экраны приложения
│   │   ├── home/                   # Главный экран
│   │   ├── servers/                # Управление серверами
│   │   ├── history/                # История тестов
│   │   └── settings/               # Настройки
│   └── theme/                      # Material 3 тема
└── service/                        # Android Services
    └── IperfTestService.kt         # Foreground Service
```

## Технические детали
- **Архитектура:** Clean Architecture (Domain, Data, UI)
- **UI Framework:** Jetpack Compose + Material 3
- **База данных:** Room + DataStore
- **Навигация:** Navigation Compose с поддержкой адаптивных макетов
- **Целевая платформа:** ARM64 (arm64-v8a)
- **Минимальная версия Android:** API 24 (Android 7.0)
- **Целевая версия:** API 34 (Android 14)
- **Языки:** Kotlin 1.9.10, Compose 1.5.4
- **Локализация:** Русский и английский языки

## Инструкции по сборке
1. Требуется установка iperf3 binary для ARM64 в `app/src/main/jniLibs/arm64-v8a/`
2. Запуск сборки: `./gradlew assembleDebug`
3. APK будет доступен в `app/build/outputs/apk/debug/`
